# Sessions

One summary per working session (human + agent, or agent-solo). This is a
log, not a duplicate of `decisions/` — put the *why* in decisions, put the
*what happened and what's left* here.

## Naming

`YYYY-MM-DD-NN-short-title.md` — `NN` handles multiple sessions same day.
Example: `2026-07-11-01-razorpay-provider-scaffold.md`.

## Template

Copy `0000-template.md` for each new session. Keep it short — a few bullet
points per section is enough. This exists so the next session (or the next
agent) can catch up in under a minute, not to be a full transcript.
